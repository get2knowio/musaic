## Error codes

Tool errors come back as a tool result with `isError` and `{code, message, details?}`.

- `INVALID_INPUT`
- `NOT_FOUND`
- `MISSING_ALBUM`
- `STALE_REVISION`
- `PROPOSAL_EXPIRED`
- `DIGEST_MISMATCH`
- `FORBIDDEN`
- `DENIED`
- `APPROVAL_EXPIRED`
- `IDEMPOTENCY_CONFLICT`
- `CURSOR_STALE`
- `BUSY`
- `RESTORING`
- `NO_LIBRARY`
- `UNAVAILABLE`
- `INTERNAL`

Transport errors are reported by the CLI, not by a tool:

- `APP_NOT_RUNNING`
- `DESCRIPTOR_INVALID`
- `NOT_PAIRED`
- `PAIRING_REVOKED`
- `INSTANCE_MISMATCH`
- `LOCKED_OUT`
- `PROFILE_UNSUPPORTED`

## Deliberately not offered

- raw SQL
- shell execution
- arbitrary filesystem paths
- reading or writing keys and secrets
- trash or delete
- database restore or backup download
- settings changes
- setting or changing agent permissions and policies, including approving its own requests

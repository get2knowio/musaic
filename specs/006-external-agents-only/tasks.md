# Tasks: External agents only (remove the built-in model provider)

**Input**: `specs/006-external-agents-only/` (spec.md, plan.md, research.md, data-model.md, contracts/, quickstart.md)

Format: `- [ ] T### [P?] description with path`. Tasks are grouped by the plan's six slices, in the plan's order; each slice ends with a checkpoint task and leaves the whole workspace green. `[P]` marks tasks whose file sets do not overlap with another `[P]` task of the same group and whose prerequisites (named in the group header or the task) are done. Paths are under `rust/crates/` unless they start with `frontend/`, `docs/`, `skills/`, `specs/`, `scripts/` or `rust/testdata/`. Run Rust commands from `rust/` and frontend commands from `frontend/`. Iterate with targeted tests (`cargo test -p <crate> [--test <file>]`, `npx vitest run <files>`); run `cargo test --workspace` and `npm test` only at a checkpoint.

**Invariants for every task**: CLAUDE.md rules 1 to 7 and the security posture hold; `unsafe` is forbidden; clippy `-D warnings` and `cargo fmt` stay clean; never run against `~/.musaic` or a real library (scratch config dir, memory secrets, `--network offline`); goldens change only deliberately, with the reason in the same change; fixture databases are copied to a temp dir before they are opened; public-text rule (no internal ids, private links or private data in code, docs, commits or issues); deferred work becomes a GitHub issue, never a TODO; new tests compare relative paths after normalising separators (Windows CI is required).

**Implementer risks, carried into the tasks they affect** (the task ids are in parentheses): pin v22 to v23 to the literal 23 (T004); never edit `delegated_work.sql` (T005); queued items of a renamed album go stale without the `AlbumRenamed` re-derivation (T025, T029); slice 1 must switch the legacy worker off and delete its tests rather than `#[ignore]` them, but must not delete the `musaic_db::ai_jobs` module, which still has compile-time callers until slice 4 (T015, T016, T031, T084); `golden/ai/http.json` stays because `validation_bytes.rs` samples its 422 bodies (T016); coalesce `publish_pending` and defer it during a bulk run (T042, T045, T061); the second resolver call is a memo hit, not a second pass (T043, T056); every check reruns once after `INPUTS_VERSION` changes (T021); no-cover-art now also sees native cover research, but judges a request linked to an old job by its history record (T021, T034); about 23 frontend files seed `["ai-providers"]` (T072); keyring delete may fail on Linux and Windows and must retry quietly without logging a value (T083, T087); bump the skill `metadata.version` before `catalog --write` (T048, T063); file the `agent_proposals` / `agent_changes` album-id issue (T037).

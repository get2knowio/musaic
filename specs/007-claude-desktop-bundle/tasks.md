# Tasks: One-click connection to Claude Desktop

**Input**: `specs/007-claude-desktop-bundle/` (spec.md, plan.md, research.md, data-model.md, contracts/, quickstart.md)

Format: `- [ ] T### [P?] description with path`. Tasks follow the plan's five slices in order; each slice ends with a checkpoint and leaves the whole workspace green. `[P]` marks tasks whose file sets do not overlap with another `[P]` task of the same group.

**Invariants for every task**: CLAUDE.md rules 1 to 7 and the security posture hold; `unsafe` is forbidden; clippy `-D warnings` and `cargo fmt` stay clean; never run against `~/.musaic`, a real library or a real Claude configuration (every test injects a scratch home and a scratch temporary root; no test may read or write `~/Library/Application Support/Claude`, `%APPDATA%\Claude` or `~/.config/Claude`); never start the packaged app; goldens change only deliberately with the reason; public-text rule (no internal ids, private links or private data in code, docs, commits or issues); deferred work becomes a GitHub issue, never an inline TODO.

**Implementer risks, carried into the tasks they affect**: `ops/agent.rs` may not name `serde_json` (T012); `musaic-commands` must stay free of db, app, axum and tokio and `musaic-cli` free of `musaic-app` (T004, T005); every new `/api` route needs an `EXTRA_ROUTES` entry and an inventory row of at least nine cells (T016, T017); the shell request must accept no body and return no path (T021); no stale time other than `Infinity` without a comment (T026); the tool catalog and skill bytes must not change (T009, T032).
